# 足底压力与IMU步态数据集
Plantar Pressure and IMU Gait Dataset

本数据集提供双侧足底压力与惯性测量单元（IMU）步态数据，可用于步态相位识别、异常步态分析和多传感器融合研究。

## 数据内容

| 类别 | 数据范围 | 清洗后采样行数 |
|---|---|---:|
| 正常步态 | 9个数据分组 | 36,448 |
| 异常步态 | 内八、外八、鸭步、足内翻，共4类 | 30,907 |

- 名义采样率为25 Hz，每行包含双侧记录。
- 每只脚包含8路足底压力，以及三轴加速度、三轴角速度和三轴磁场数据。
- 提供31个可追溯源文件、清洗后的连续数据、已有规则参考标签、字段说明和校验脚本。
- 部分源文件本身已预处理，不全部属于滤波前的硬件原始数据。

## 下载与目录

下载本仓库中的数据集ZIP文件并解压：

- `data/01_source/`：匿名化后的可用源数据。
- `data/02_cleaned/`：正常及异常步态清洗数据，含已有规则参考标签。
- `data/03_full_marked/`：异常步态全量处理数据及质量标记。
- `metadata/`：文件清单、字段字典、分组来源和校验信息。
- `docs/`：数据来源、标签方法和使用说明。
- `scripts/`：数据读取示例与校验脚本。

## 相位标签

| 编码 | 相位 | 本数据集中的含义 |
|---:|---|---|
| -1 | Excluded | 未纳入有效标注的采样点 |
| 0 | SW | 摆动期 |
| 1 | HS | 规则定义的支撑前期 |
| 2 | FF | 规则定义的支撑中期 |
| 3 | HO | 规则定义的支撑后期 |

相位标签由压力接触状态和持续时长规则生成，属于规则参考标签，不是同步视频、测力台、独立人工或临床真值。

## 使用注意事项

- 训练与测试应保持同源记录隔离，避免随机打散相邻采样点或重叠窗口。
- 构建窗口时，应检查来源、脚别、连续段、原始行号及时间间隔，禁止跨越不连续区间。
- 测量值沿用既有处理结果，具体单位与处理方法请查阅包内说明。

## 读取与校验

解压后，在数据集根目录执行：

python scripts/load_example.py
python scripts/verify_release.py

以上脚本仅依赖Python标准库。
